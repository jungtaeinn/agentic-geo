fix: 머지 전 리뷰가 실행 재현한 blocker 세 건

세 리뷰어가 각각 종단 재현한 것들이다. 셋 다 기존 시험이 덮지 못했다.

**① 계약의 사설 사본이 접수 단계를 막고 있었다**

`contracts/usage-contract.ts`가 "단일 출처"로 소유한 지시 동사 판정이 `normalize.ts`에 한 벌 더 있었고, 이미 어긋나 있었다 — 계약에만 세정 동작(`hasWashActionCue`)을 넣었기 때문이다.

```
거품을 충분히 낸 후 깨끗이 씻어냅니다.   계약 true / 사본 false
부드럽게 씻어낸 뒤 물기를 정돈합니다.     계약 true / 사본 false
```

그 사본이 접수 게이트(`isUsageInstruction` → `inferPdpEvidenceRoles`)라서, 클렌저의 세정 단계는 계약을 고쳐도 애초에 `usage` 역할을 받지 못했다. 계약이 고쳐졌다고 적은 changeset이 실제로는 발효되지 않고 있었다.

사본을 지우고 계약을 읽게 했다. 사본만 알던 형태(`사용 할 때`, `분사하고`)는 계약으로 흡수했다.

**② 손자 그룹이 통째로 사라졌다**

`ocrLayoutSections`가 최상위 그룹과 직계 자식만 훑었다. 프롬프트가 중첩을 적극 유도하는데("a chart body under its caption"), 3단 중첩에서는 이렇게 된다.

```
g1 "CLINICAL RESULTS" → g2 "Skin barrier recovery" → g3 "Improved after 4 weeks…"
→ [{ heading: "CLINICAL RESULTS", items: [] }]
```

정족수를 통과했으니 줄 파서로 되돌아가지도 않고, 진단에는 `groupsKept: 3`으로 정상 집계된다 — 그 이미지의 유일한 산문이 조용히 사라진다. 하위 트리 전체를 인쇄 순서대로 훑는다(`parentId`가 만드는 고리는 검증이 걸러 주지 않으므로 방문 기록을 둔다).

**③ 영문 지시가 제목으로 승격됐다**

제목 판정이 종결어미·조사 배제를 한국어에만 두어, 3어절 이하 영문 지시가 무조건 제목이 됐다.

```
HOW TO USE / Dispense … / Rinse with water / Use morning and evening …
→ `Rinse with water`가 usage에서 소멸
사용 방법 / 적당량을 … / 물로 씻어냅니다 / 아침 저녁으로 …
→ 3개 전부 발행
```

한국어는 종결어미와 조사로 "이 줄은 절이다"를 표시하지만 영문에는 그 표지가 없다. 절은 기능어로 성분을 잇는다는 사실로 규정했다 — 기능어가 뒤에 성분을 데리고 있으면 절이고, 마지막 낱말이면 라벨이다(`RECOMMENDED FOR`). 전부 대문자인 줄은 조판 관례상 라벨이므로 면제한다(`HOW TO USE`).

**④ 선언된 역할이 값 자격까지 면제했다**

절 제목이 역할을 선언하면 값 자격 검사 전체를 건너뛰었다.

```
효과 / +63.6% / 7.05 oz. / 200 g      → effects = ["+63.6%", "7.05 oz. / 200 g"]
효과 / 0 / 10 / 20 / ※ …시험 결과      → effects = ["※ 성인 여성 30명 대상 4주 사용 시험 결과"]
```

역할을 정하는 것은 관계이고 값이 될 수 있는지를 정하는 것은 그 줄의 형태다 — 두 질문을 하나로 묶은 것이 결함이었다. 선언 항목에도 형태 검사를 걸었다: 수치와 단위를 걷어낸 뒤 아무 말도 남지 않으면 값이 아니고, 참조 기호로 열리는 줄은 각주다.

그 과정에서 단위 열거도 걷어냈다. 형제 모듈이 이미 "단위 목록을 열거하지 않는다"고 규정했는데 이 함수는 열거하고 있어, 목록에 없는 `120 mmHg`·`1.7 ㎍/㎖`가 측정 주장으로 통과했다. 숫자 뒤의 짧은 비숫자 꼬리가 단위라는 같은 규정을 쓴다.
