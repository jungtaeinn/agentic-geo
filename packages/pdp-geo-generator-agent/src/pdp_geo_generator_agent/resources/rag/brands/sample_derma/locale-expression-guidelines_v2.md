# Demo Derma Locale Expression Guidelines v2

> Fictional public example; apply only with current product evidence.

## Brand-Specific Locale Overlay

- Use clear, non-medical wording for source-stated moisture, comfort, texture, or routine facts.
- Preserve the source's market, product, and qualifier whenever a test or certification is mentioned.
- Do not turn “for daily use” into a universal safety statement.
- Do not turn barrier, comfort, or sensitivity language into disease treatment.
- If Korean and English source scopes differ, emit only the supported scope for each locale.
